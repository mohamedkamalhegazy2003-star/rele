# تطبيق إدارة العقارات - النسخة المعدلة 2.0

تم تنفيذ المراحل المطلوبة على بنية المشروع الحالية، وهي Flutter + SQLite (`sqflite`) وليست Room أصلية.

## أهم الإضافات
- حقل موقع العقار ورقم هاتف بديل للمستأجر مع Migration لقاعدة البيانات.
- ID ثابت لكل عقار وسيريال إيصالات مرتبط به: العقار 1 يبدأ 100001، العقار 2 يبدأ 200001، وهكذا.
- تعديل وحذف عمليات السداد مع إعادة تحديث المستحق المرتبط بالعملية.
- شاشة مرافق/خدمات لكل عقار، تشمل كهرباء/مياه/غاز/خدمات أخرى. بند خدمات أخرى يتطلب ملاحظات وقيمة.
- عند سداد مستحق المرافق بالكامل يتم تصفيره وإخفاؤه من قائمة المستحقات المفتوحة.
- حساب خاص لكل عقار مع تقرير PDF مستقل.
- تقرير مالي مجمع لكل العقارات مع PDF شامل وتفاصيل العمليات.
- تسجيل دخول بكلمة المرور + بصمة.
- عند أول تشغيل تُنشأ قاعدة البيانات بحسابين افتراضيين:
  - الرئيسي: `admin` / `admin123`
  - البديل: `backup` / `backup123`
  يوصى بتغيير كلمة المرور فور الدخول من الإعدادات.
- شاشة إعدادات لتعديل الاسم واسم المستخدم وكلمة المرور.
- حتى 20 صورة لبطاقة المستأجر وحتى 20 صورة للعقد، مع ترحيل الصورة القديمة تلقائياً إلى القائمة الجديدة.
- إشعار محلي دوري عبر WorkManager كل 4 ساعات (قد يؤخره Android قليلاً حسب تحسينات البطارية).
- إضافة صلاحية Android 13+ للإشعارات وصلاحية البصمة تلقائياً أثناء Build GitHub Actions.

## قاعدة البيانات
تم رفع إصدار SQLite إلى `6`. الترقية تحافظ على البيانات الحالية وتضيف الأعمدة والجداول الجديدة، كما تنشئ سيريالات للإيصالات القديمة بناءً على ID العقار.

## بناء APK
1. ارفع محتويات المجلد إلى GitHub.
2. افتح **Actions** ثم شغّل **Build APK**.
3. الـ Workflow ينشئ Android folder، يضبط صلاحيات الإشعارات والبصمة و`FlutterFragmentActivity`، ثم يشغّل `flutter analyze` وبعده يبني APK.
4. نزّل Artifact باسم `real-estate-apk`.
